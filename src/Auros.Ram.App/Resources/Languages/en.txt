# INSTRUCCIONES PARA TRADUCIR (a mano o con una IA):
# - Cada línea tiene el formato ID=texto. Traducir solo el texto que está después del primer "=".
# - No modificar los ID ni los títulos de sección entre corchetes, no agregar ni quitar líneas y mantener el orden.
# - Las líneas que empiezan con "#" son comentarios: dejarlas igual.
# - Conservar exactamente los marcadores {0}, {1}, etc. y los \n (saltos de línea); se pueden mover dentro de la frase.
# - Conservar los símbolos y la puntuación especial: …, →, ·, %, ✕.
# - Usar terminología de gestión de riesgos y auditoría (riesgo, impacto, probabilidad de ocurrencia,
#   criterio de materialidad, unidad de negocio). Preferir textos cortos: son botones, títulos y etiquetas.
# - En [Idioma], Codigo es el código ISO del idioma (en, pt, fr, it, de…) y Nombre, el nombre del idioma
#   escrito en ese idioma (English, Português, Français…). Cultura es el formato de fechas y números del país
#   (en-US: 11/1/2026; en-GB: 01/11/2026; pt-BR: 01/11/2026); si queda vacía se usa el habitual del idioma.
# - Un texto que falte o pierda un marcador se muestra en español.
